# Robopilot AI

Futuristic, animated marketing site for **Robopilot AI** — built with Next.js, inspired by [Discord](https://discord.com/) marketing motion (dark layered surfaces, bold type, floating reactive elements, cursor-driven ambience).

## Stack

- Next.js 16 (App Router)
- React 19 + TypeScript
- Tailwind CSS 4
- Framer Motion
- Lucide icons

## Pages

- `/` — Home
- `/about` — Company story
- `/services` + `/services/[slug]` — Service catalog & detail
- `/industries` — Sector coverage
- `/work` — Featured concepts
- `/process` — Delivery model
- `/insights` — Thought leadership
- `/contact` — Inquiry form (API: `POST /api/contact`)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
